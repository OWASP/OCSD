# Objectives for Module 16 – Secure Developer Environment and Security Awareness

This module covers the security of the workstations, tools, services, and habits that developers use to build software.

A successful candidate can:

- Identify the assets in a development environment and the threats that make developer workstations high-value targets
- Recognize workstation controls that limit privileges, separate environments, and protect lost or unattended devices
- Recognize developer responsibilities under organizational security policies, including when to report or escalate a concern
- Identify how local tools, extensions, repository settings, and scripts can run code with the developer's access
- Recognize when information must not be submitted to online services, code assistants, or other third-party tools
- Identify safe handling of secrets and sensitive data on workstations, in repositories, and in shared diagnostic information
- Recognize risks in remote access, untrusted networks, and development services exposed beyond the local machine
- Distinguish the isolation that containers, virtual machines, and managed workspaces provide, and recognize configurations that weaken it
- Recognize social engineering aimed at developers and indicators of a compromised workstation or account
- Identify appropriate first responses to a suspected compromise or exposed secret, and sources of security information about development tools

## Expected competency

Candidates can recognize insecure practices in a described development environment.
They can identify the control, safer alternative, or response that reduces the risk.
