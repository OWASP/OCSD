# Objectives for Module 4 – Input Validation and Output Encoding

This module covers the safe handling of untrusted data in web applications: validating input on the server, preventing injection with safe APIs, and encoding output for the context in which it is used.

A successful candidate can:

- Identify the sources of untrusted data that reach a web application
- Distinguish validation, sanitization, normalization, and output encoding, and select the appropriate technique for a given situation
- Apply allowlist-based, server-side validation of type, length, range, format, and allowed values
- Explain why client-side validation improves usability but provides no security
- Explain how injection vulnerabilities occur when untrusted data changes the meaning of a query, command, or document
- Prevent SQL, OS command, LDAP, XPath, and XML external entity injection using parameterized APIs and secure parser configuration
- Apply context-specific output encoding to prevent cross-site scripting in HTML, attribute, JavaScript, and URL contexts
- Use a maintained HTML sanitizer when an application must accept rich content
- Create positive and negative tests for validation rules, injection defenses, and output encoding

## Competency

Candidates can implement server-side validation and context-appropriate output handling for a web application feature that accepts untrusted data.
They can recognize injection and cross-site scripting weaknesses caused by missing or incorrect input and output handling, and fix them with parameterized APIs, output encoding, and validation.
