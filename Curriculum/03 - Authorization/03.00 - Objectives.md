# Objectives for Module 3 – Authorization

This module covers the design, implementation, and testing of authorization in web applications.

A successful candidate can:

- Distinguish authorization from authentication
- Describe an authorization decision in terms of a subject, action, resource, policy, and relevant context
- Apply least privilege, deny by default, and complete mediation to authorization rules
- Compare access control lists and role-based, attribute-based, and relationship-based access-control models
- Enforce function-level, object-level, and property-level authorization in trusted application code
- Identify horizontal, vertical, and cross-tenant authorization failures
- Create positive and negative tests from an application's authorization rules
- Recognize missing or inconsistent authorization checks during code review

## Competency

Candidates can implement and test authorization for a web application feature from a defined access policy.
They can identify weaknesses that expose another user's data or privileged functions.
