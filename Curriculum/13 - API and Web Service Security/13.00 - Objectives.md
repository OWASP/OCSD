# Objectives for Module 13 – API and Web Service Security

This module covers the security of application programming interfaces (APIs) and web services that applications provide and consume.

A successful candidate can:

- Identify the risks described in the OWASP API Security Top 10 and how API design exposes them
- Recognize how authentication and object-, property-, and function-level authorization apply to every API request
- Identify request validation and response filtering controls that limit what an API accepts and returns
- Recognize resource consumption risks in APIs and the limits that control them
- Distinguish security concerns specific to REST, GraphQL, SOAP, and gRPC APIs
- Identify controls for receiving and sending webhooks and for API features that fetch user-supplied URLs
- Recognize the risks of consuming third-party APIs and treating their responses as trusted
- Identify the role of API inventories, documentation, versioning, and gateways in API security
- Identify test cases that reveal API authorization, validation, and resource consumption failures

## Expected competency

Candidates can recognize whether an API design or implementation protects its data and functions.
They can identify missing authorization, excessive data exposure, unrestricted resource consumption, and unsafe handling of webhooks and third-party APIs.
