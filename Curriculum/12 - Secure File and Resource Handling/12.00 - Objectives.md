# Objectives for Module 12 – Secure File and Resource Handling

This module covers how applications accept, store, process, and serve files, and how they access files and resources identified by user input.

A successful candidate can:

- Recognize the risks of file uploads, downloads, file processing, and file paths derived from user input
- Identify validation controls for uploaded files, including type, content, size, and file name checks, and their limits
- Identify secure storage for uploaded files, including location, naming, execution prevention, access control, and malware scanning
- Identify response headers and access controls for serving files to users
- Recognize path traversal and file inclusion vulnerabilities and distinguish effective defenses from ineffective ones
- Recognize the risks of processing archives and complex file formats, including Zip Slip and decompression bombs
- Recognize server-side request forgery in features that fetch remote files or resources
- Identify safe handling of temporary files and the race conditions that affect file operations
- Identify test cases that reveal file handling weaknesses

## Expected competency

Candidates can recognize whether an application handles files and file paths securely.
They can identify upload, storage, download, and processing weaknesses that lead to code execution, data exposure, or denial of service.
