# Objectives for Module 10 – Software Supply Chain Security

This module covers the security of software components and the processes that bring them into an application.

A successful candidate can:

- Identify supply chain risks in code, dependencies, builds, and distribution
- Recognize security, maintenance, and licensing requirements for third-party components
- Know about safe practices for adding, updating, and removing dependencies
- Distinguish component inventories, software composition analysis (SCA), and static application security testing (SAST)
- Recognize the purpose and limits of hashes, digital signatures, and provenance
- Identify checks and tests for dependency updates and artifact verification

## Expected competency

Candidates can recognize whether a dependency is suitable for an application.
They can identify dependency risks and appropriate responses.
