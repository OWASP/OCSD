# Objectives for Module 14 – Secure Configuration and Deployment

This module covers how applications and their runtime environments are configured and deployed so that production systems expose only what they need.

A successful candidate can:

- Recognize secure defaults, hardening, and attack surface reduction as principles for configuring application components
- Identify web and application server settings that expose files, directory contents, administrative interfaces, or version information
- Identify debug features, test files, development dependencies, and documentation that must not reach production
- Distinguish configuration from code, and identify how deployed applications obtain secrets and credentials securely
- Identify least-privilege runtime identities, permissions, and network exposure for applications, services, and containers
- Recognize the purpose of common security headers and browser policies, and identify unsafe Cross-Origin Resource Sharing (CORS) configurations
- Recognize the shared responsibility model and the security settings that application teams control on managed platforms
- Identify controls that protect deployment pipelines, deployment credentials, and production releases
- Identify checks that detect insecure or changed configuration before and after deployment

## Expected competency

Candidates can recognize whether a deployed application and its environment are configured securely.
They can identify exposed files and features, excessive privileges, unsafe secrets handling, and missing protections in the deployment process.
