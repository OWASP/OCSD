# Objectives for Module 3 – Authorization

This module covers authorization decisions, access-control models, enforcement, common failures, and testing in web applications.

A successful candidate can:

- Distinguish authorization from authentication
- Identify the subject, action, resource, policy, and relevant context in an authorization decision
- Recognize the role of least privilege, deny by default, and complete mediation in authorization rules
- Distinguish among access control lists, role-based access control, attribute-based access control, and relationship-based access control
- Identify trusted enforcement points for function-level, object-level, and property-level authorization
- Identify horizontal, vertical, and cross-tenant authorization failures
- Identify positive and negative test cases for an application's authorization rules
- Recognize missing or inconsistent authorization checks in code examples and application designs

## Expected competency

Candidates can recognize whether an authorization design enforces a defined access policy and whether its tests verify that policy.
They can identify gaps that expose another user's data, allow access across tenant boundaries, or permit access to privileged functions.
