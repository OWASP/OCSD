# Objectives for Module 9 – Secure Communications

This module covers how web applications protect traffic between browsers, proxies, and services.

A successful candidate can:

- Identify what Transport Layer Security (TLS) protects on a connection
- Recognize gaps in transport protection after TLS termination and between services
- Distinguish safe TLS version and cipher choices, including those that provide forward secrecy
- Recognize certificate verification failures and responses that preserve endpoint verification
- Identify when certificates need renewal and when compromised keys must be replaced
- Distinguish server-authenticated TLS from mutual TLS
- Distinguish how HTTPS redirects, HTTP Strict Transport Security (HSTS), and mixed-content controls affect browser connections
- Identify the application checks needed on secure WebSocket connections

## Expected competency

Candidates can identify which connections are protected and which peer identities are verified in a web application that receives and makes requests.
They can recognize unsafe settings, gaps in protection, and appropriate responses when a connection fails verification.
